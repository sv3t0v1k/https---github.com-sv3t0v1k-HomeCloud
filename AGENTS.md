# Постоянные правила работы с HomeCloud

1. Строго соблюдать утверждённый scope. Не выполнять unrelated refactoring, переименование или форматирование вне задачи.
2. Не начинать следующую Phase без прямого указания владельца проекта.
3. Для сложных задач использовать subagents только с узкими, непересекающимися ролями и явно заданными границами.
4. Critical/security изменения должны получить независимый review, не выполненный автором изменения.
5. Результаты subagents всегда проверяет основной исполнитель по фактическим diff, тестам и требованиям; отчёт subagent не является доказательством.
6. Не повторять безрезультатно один и тот же подход. После двух одинаковых неудач остановиться, зафиксировать причину и сменить метод; при отсутствии безопасного пути запросить решение владельца.
7. Проверки выполнять по порядку: targeted tests → полный набор тестов → lint → build. Пропущенную проверку и причину указывать явно.
8. Перед завершением обязательно проверить `git diff` и `git status`, отделить собственные изменения от параллельной работы и убедиться в отсутствии посторонних файлов.
9. Не изменять незавершённую работу другого агента без прямого разрешения. При пересечении файлов остановиться и согласовать границы.
10. Весь создаваемый Git-текст — сообщения commit, названия веток и тегов, описания merge/rebase — писать только на русском языке.
11. Статус `COMPLETE` устанавливать только после проверки acceptance criteria и наличия подтверждающего commit/checkpoint.
