## Поведение

Из любой папки доступна команда «Поиск во всех файлах» и Ctrl/Cmd+K. Она
открывает отдельную страницу `/files/search`; сочетание не перехватывается
в редактируемых полях и модальных диалогах. Фокус перемещается в поле.
Локальный фильтр текущей папки сохранён и не вызывает глобальный API.

Глобальный поиск запускается только Enter/кнопкой. Название после trim должно
содержать 2–100 UTF-16 code units без внутренних ASCII control/DEL. Запрос и
offset находятся в URL; некорректный или неоднозначный URL не вызывает API.
Ввод не создаёт запрос на каждый символ. Новый запрос сбрасывает страницу.

Ответ — собственные safe SearchFile/SearchFolder DTO. На странице 20 объектов,
сначала папки, затем файлы в порядке backend. Выделение совпадения создаётся
React-узлами, без HTML-интерпретации имени. Интерфейс показывает диапазон,
не выдумывает total и не пересортировывает страницы. Next недоступна после
offset=10000 даже при hasMore; пользователю предлагается уточнить запрос.

Для файлов доступны существующие предпросмотр, native download и ShareDialog;
для папок — открытие по folder id и sharing по shareFileId. Новых серверных
мутаций и массовых действий над устаревшей выдачей нет.

## Путь и навигация

Кнопка расположения раскрывает полный путь **одного выбранного результата**.
Загружается только цепочка предков через существующий getFolder; children
дерева не перечисляются. Путь отображается рядом с соответствующей строкой,
каждый предок — обычная внутренняя ссылка. Имена не реконструируются из догадок.
Кэш предков ограничен 256 узлами/60 сек в памяти страницы; циклы, неверные id,
невалидные metadata и цепочки длиннее 256 уровней закрываются безопасной ошибкой.
Для очень глубоких деревьев применяется обычный API rate limit; при 429 путь
можно повторить вручную после Retry-After с переиспользованием полученных узлов.

«Показать в папке» открывает parentId/корень, передаёт проверенный id для
выделения и фокусирует фактически загруженную строку. Если объект перемещён
или удалён, выводится сообщение об изменившемся расположении. История браузера
сохраняет query/page/scroll и фокус результата. Ссылки возврата внутренние;
значения из location state не являются источником прав доступа.

Оба механизма завершения login возвращают pathname+query, поэтому после 401
и повторного входа запрос/страница не теряются. Owner/session generation
разделяют поисковый кэш; результаты предыдущего аккаунта не переиспользуются.

## Запросы, кэш и ошибки

SearchSessionProvider находится в общей оболочке `/files` вместе с очередью
загрузок. Очередь и её панель не пересоздаются при переходах папка ↔ поиск.
Session memory cache: максимум 10 страниц, TTL 60 сек. Токены обновляются
существующим API client; обычная refresh-ротация не меняет владельца кэша.
Смена owner/generation, logout или unmount очищают кэш и отменяют запросы.
StrictMode не дублирует один поисковый запрос; устаревшие ответы игнорируются.

| Состояние | Реакция интерфейса |
| --- | --- |
| Пустой запрос | Объяснение области поиска без случайных результатов |
| Невалидный ввод/URL | Локальная ошибка у поля, API не вызывается |
| Загрузка | Skeleton, aria-busy, одно объявление статуса |
| Пустая выдача | «Ничего не найдено», предложение уточнить название |
| HTTP 400 | Безопасное объяснение, действие «Изменить запрос» фокусирует поле |
| HTTP 401 | Штатный refresh; затем login с сохранением адреса поиска |
| HTTP 429 | Общий cooldown; Retry-After seconds/date, fallback 60 сек; ручной повтор |
| HTTP 503/сеть | Запрос сохранён, повтор только по действию пользователя |
| Ошибка обновления cached страницы | Предыдущие строки явно подписаны; действия отключены до успешного обновления |
| 403/404 пути/объекта | Недоступное/изменившееся расположение; безопасное сообщение |

Ошибки не вставляют raw backend details в интерфейс. Нет polling, фоновой
предзагрузки страниц или автоматического повторения 429/503. Результаты и
история поиска дополнительно не сохраняются в localStorage/sessionStorage.
Сам q видим в URL и истории браузера — приватность этой истории не обещается.

## Визуальная система и доступность

Существующая UX v2: графитовый фон, оливковый акцент, Manrope/JetBrains Mono,
знакомые SVG Icon, ActionMenu, PreviewModal и ShareDialog. Плотный список,
тонкие разделители, явно подписанное поле и один основной CTA. На узком экране
метаданные/действия переносятся, topbar укладывается в 320 px. Focus ring,
touch targets 44 px, aria names полного имени файла и reduced-motion сохранены.
Закрытие предпросмотра и расположения возвращает фокус к исходной кнопке.

Проверки и ограничения: [приёмочный отчёт](evidence/global-search-gs1b/acceptance.md),
[независимый review](evidence/global-search-gs1b/security-review.md).
GS-1B не объединять и серверы не обновлять без подтверждения владельца.
