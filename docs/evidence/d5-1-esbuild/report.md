[Последний официальный esbuild 0.28.2](https://github.com/evanw/esbuild/releases/tag/v0.28.2) всё ещё содержит Go **1.26.5** в опубликованном npm `@esbuild/linux-x64` ELF, поэтому обновление esbuild до последней версии не закрывает `CVE-2026-111943`. Ни 0C/0H, ни source attestation этого бинарника не заявляются.

Поддерживаемая upstream-альтернатива — `vite 8.3.5` без зависимости esbuild и `@vitejs/plugin-react 6.1.2` с peer Vite 8; `vitest 4.1.11` допускает Vite 8. `npm ci` воспроизвёл lock (`package-lock.json` SHA256 `956c95d63910ec3d9f31ccc18fe5a90dccd134f89e0c305ef28b639750dcfce8`); `esbuild` и `@esbuild/*` отсутствуют в lock и установленном дереве. Новый Vite использует `rolldown 1.2.16` и `lightningcss 1.33.0`. Это major upgrade frontend build tooling, поэтому функциональные тесты обязательны.
