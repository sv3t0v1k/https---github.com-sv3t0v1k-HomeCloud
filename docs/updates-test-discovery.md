# Updates: обнаружение TEST-сборок (без установки)

- В существующем разделе «Обновления» настройка `UPDATE_CHANNEL=test` выбирает TEST, отсутствие/другое значение — прежний `release`.
- TEST читает защищённую ветку `test`, последний успешный push workflow `ci-v2-fast.yml`, его артефакт `test-channel-<attempt>` и один `test-channel.json`. Проверяет SHA-256, принадлежность CI, идентичность миграций, происхождение commit и точные GHCR digests. Не использует SSH, systemd, Docker API, не скачивает образы, не устанавливает обновления.
- Для скачивания GitHub Actions artifact требуется `UPDATE_GITHUB_TOKEN` с **Actions: read** для репозитория. На GHCR может дополнительно потребоваться `UPDATE_GITHUB_USER` с pull-доступом. Токен остаётся в конфигурации backend, не в браузере.
- Если установленная версия неизвестна, интерфейс не предлагает обновление. Оператор должен отдельно подтвердить действительный SHA и миграции в существующем файле installed metadata. Никаких автоматических изменений metadata или образов в этом этапе.
- Пока ветка `test` отсутствует, GitHub API недоступен или нет корректного манифеста, кандидат не объявляется. Изменения production и Mac Pro не требуются.
- Перед эксплуатационной приёмкой на мини-ПК необходимо проверить доступ к GitHub Actions artifact и GHCR из сети сервера. Локальные тесты с заглушками не доказывают сетевой доступ.
